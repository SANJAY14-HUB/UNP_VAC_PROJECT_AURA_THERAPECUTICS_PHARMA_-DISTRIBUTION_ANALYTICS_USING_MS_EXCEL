# UNP_VAC_PROJECT_AURA_THERAPECUTICS_PHARMA_-DISTRIBUTION_ANALYTICS_USING_MS_EXCEL

Aura Therapecutics Pharmaceutical Distribution Data Analytics – In Collaboration with UNP Education

Completed a data analytics project using Microsoft Excel with both manual and AI-assisted approaches. Performed data cleaning, preprocessing, missing value imputation, duplicate removal, outlier treatment, data encoding, hypothesis testing, correlation analysis, and regression modelling. Created charts, plots, and interactive dashboards to analyze pharmaceutical sales, revenue, and distribution performance, gaining practical experience in data analytics and business insights.
